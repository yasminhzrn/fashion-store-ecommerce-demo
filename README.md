# 🌸 Mina's Fashion Store (Front-End Demo)

A responsive front-end fashion e-commerce website built using HTML, CSS, and JavaScript.

## ✨ Live Demo

https://yasminhzrn.github.io/fashion-store-ecommerce-demo/

## Features

- Fashion-themed e-commerce homepage
- Cute pastel UI design
- Responsive layout
- Product showcase sections
- Shopping cart interface
- Promotional banners
- Built with vanilla HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## About

This project was created as a front-end portfolio project to demonstrate responsive web design and user interface development. It is intended for educational and showcase purposes only. No real purchases or payments are processed.

## Future Improvements

- Add interactive shopping cart

- Additional pages (Shop, About, Contact, Cart)
